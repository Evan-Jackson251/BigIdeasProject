### Dataset 1: City of Pittsburgh Parks
https://data.wprdc.org/datastore/dump/fa329e3d-89ff-4708-8ddf-81bfedcad11d
This dataset lists all the parks in Pittsburgh and what town they are located in
### Dataset 2: Neighborhoods
https://data.wprdc.org/dataset/neighborhoods2
This dataset contains general information about each neighborhood in Pittsburgh. It lists perimeter size, acres, sq miles and more.
### Dataset 3: Pittsburgh Neighborhood Atlas, 1977
https://data.wprdc.org/dataset/pittsburgh-neighborhood-atlas-1977
This dataset uses crime rate statistics from 1973-1975 in each Pittsburgh Neighborhood.
## Description
This repository is for a project that attempts to find the best neighborhood in Pittsburgh by measuring the number of parks, neighborhood size, and crime rate.
